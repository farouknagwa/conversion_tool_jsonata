MATCHING (Matching Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

MATCHING PART STRUCTURE:
{
  "n": 1,
  "type": "matching",
  "stem": "string (HTML content)",
  "items": {
    "A": [
      {
        "value": "string (HTML content)",
        "label": "string (A1, A2, A3, etc.)"
      },
      ...
    ],
    "B": [
      {
        "value": "string (HTML content)",
        "label": "string (B1, B2, B3, etc.)",
        "matches": "string (A1, A2, etc.)"
      },
      ...
    ]
  },
  "correct_answer": [
    {
      "A": "string (HTML content)",
      "B": "string (HTML content)"
    },
    ...
  ],
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "matching" for this question type

stem (string, required):
- HTML content containing the question text
- May include formatting tags (p, span, strong, etc.)

items (object, required):
- Contains two groups: A and B
- items.A: Array of items from group 1 (left column), each containing:
  * value: HTML content of the item text
  * label: Display label (A1, A2, A3, etc.)
- items.B: Array of items from group 2 (right column), each containing:
  * value: HTML content of the item text
  * label: Display label (B1, B2, B3, etc.)
  * matches: Label of the matching item from group A (e.g., "A1", "A2")
- Labels are automatically generated based on index order (A1, A2, A3... for group A; B1, B2, B3... for group B)

correct_answer (array, required):
- Array of matching pairs, each containing:
  * A: HTML content of an item from group 1
  * B: HTML content of the matching item from group 2
- Each pair represents a correct match between items in group A and group B
- Array is ordered by the index order of items in group A

explanation (string or null, optional):
- HTML content explaining the correct matches
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- Exactly two groups must exist (group 1 and group 2)
- items.A and items.B must be non-empty arrays
- Each item in items.B must have a matches field pointing to a valid label in items.A
- correct_answer array must contain all valid matches
- Number of correct_answer pairs must match number of items in items.A
