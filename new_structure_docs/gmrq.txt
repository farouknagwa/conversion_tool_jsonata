GMRQ (Grouped Multiple Response Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

GMRQ PART STRUCTURE:
{
  "n": 1,
  "type": "gmrq",
  "stem": "string (HTML content)",
  "items": {
    "A": [
      {
        "label": "string (A, B, C, etc. or Arabic equivalent)",
        "value": "string (HTML content)",
        "is_correct": boolean
      },
      ...
    ],
    "B": [
      {
        "label": "string (X, Y, Z, etc. or Arabic equivalent)",
        "value": "string (HTML content)",
        "is_correct": boolean
      },
      ...
    ]
  },
  "correct_answer": {
    "A": "string (HTML content)",
    "B": "string (HTML content)"
  },
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "gmrq" for this question type

stem (string, required):
- HTML content containing the question text
- May include formatting tags (p, span, strong, etc.)

items (object, required):
- Contains two groups: A and B
- items.A: Array of items from group 1, each containing:
  * label: Display label (A, B, C, D, etc. for English; أ, ب, ج, د, etc. for Arabic)
  * value: HTML content of the item text
  * is_correct: Boolean indicating if this item is the correct choice from group 1
- items.B: Array of items from group 2, each containing:
  * label: Display label (X, Y, Z, AA, AB, etc. for English; س, ص, ض, etc. for Arabic)
  * value: HTML content of the item text
  * is_correct: Boolean indicating if this item is the correct choice from group 2
- Labels for group A: English (A, B, C, D, E, F, G, H, I, J) or Arabic (أ, ب, ج, د, ه, و, ز, ح, ط, ي)
- Labels for group B: English (X, Y, Z, AA, AB, AC, AD, AE, AF, AG) or Arabic (س, ص, ض, ط, ظ, ع, غ, ف, ق, ك)

correct_answer (object, required):
- Contains the correct answer pairing:
  * A: HTML content of the correct item from group 1 (items.A)
  * B: HTML content of the correct item from group 2 (items.B)

explanation (string or null, optional):
- HTML content explaining the correct answer
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- Exactly two groups must exist (group 1 and group 2)
- Each group must have exactly one item with is_correct = true
- correct_answer.A must match the item in items.A with is_correct = true
- correct_answer.B must match the item in items.B with is_correct = true
- All items must have label, value, and is_correct fields
