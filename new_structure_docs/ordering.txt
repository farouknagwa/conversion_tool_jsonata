ORDERING (Ordering Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

ORDERING PART STRUCTURE:
{
  "n": 1,
  "type": "ordering",
  "stem": "string (HTML content)",
  "direction": "string (vertical or horizontal, lowercase)",
  "items": [
    {
      "value": "string (HTML content)",
      "display_order": integer,
      "correct_order": integer
    },
    ...
  ],
  "correct_answer": [
    "string (HTML content)",
    ...
  ],
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "ordering" for this question type

stem (string, required):
- HTML content containing the question text
- May include formatting tags (p, span, strong, etc.)
- Typically asks student to arrange items in correct order

direction (string, required):
- Layout direction for displaying items
- Must be "vertical" or "horizontal" (always lowercase)
- "vertical": Items displayed in a vertical list
- "horizontal": Items displayed in a horizontal sequence
- Automatically converted to lowercase regardless of input case

items (array, required):
- Array of items to be ordered, each containing:
  * value: HTML content of the item text
  * display_order: Integer indicating the initial display order (from fixed_order)
  * correct_order: Integer indicating the correct position in the sequence
- Items are sorted by display_order for initial presentation
- Student must arrange items according to correct_order

correct_answer (array, required):
- Array of HTML content strings in correct order
- Generated by sorting items by correct_order
- Each element is the value of an item in the correct sequence
- Length must match number of items

explanation (string or null, optional):
- HTML content explaining the correct order
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- direction must be "vertical" or "horizontal" (case-insensitive input, lowercase output)
- items must be a non-empty array
- Each item must have value, display_order, and correct_order
- correct_answer must be an array with same length as items
- correct_answer must contain all item values in correct_order sequence
