GAP (Gap Text Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

GAP PART STRUCTURE:
{
  "n": 1,
  "type": "gap",
  "stem": "string (HTML content with gap markers)",
  "gap_keys": [
    {
      "value": "string",
      "display_order": integer,
      "correct_order": integer (optional)
    },
    ...
  ],
  "correct_answer": "string (HTML content with gaps filled)",
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "gap" for this question type

stem (string, required):
- HTML content containing the question text with gap markers
- Gap markers are HTML spans with attribute data-node-variation="gap"
- Example: <span data-node-variation="gap">_____</span>
- Number of gaps must match number of gap_keys with correct_order

gap_keys (array, required):
- Array of gap key objects, each containing:
  * value: The text value for this gap option
  * display_order: Integer indicating display order (1-based, starts from 1)
  * correct_order: Integer indicating correct position (optional, only for correct answers)
- Display order corresponds to the order items appear in the selection list
- Correct order corresponds to the position in the stem where this value should be placed
- Only gap_keys with correct_order are used to construct the correct_answer

correct_answer (string, required):
- HTML content with all gap markers replaced by correct values
- Generated by replacing each gap marker in stem with the corresponding gap_key value (in correct_order sequence)
- Represents the complete filled-in question with all correct answers

explanation (string or null, optional):
- HTML content explaining the correct answer
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- gap_keys must be a non-empty array
- Each gap_key must have value and display_order
- Number of gap_keys with correct_order must match number of gaps in stem
- stem must contain gap markers (<span data-node-variation="gap">...</span>)
- correct_answer must be a string containing the filled-in stem
