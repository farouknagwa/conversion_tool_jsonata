STRING (String Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

STRING PART STRUCTURE:
{
  "n": 1,
  "type": "string",
  "stem": "string (HTML content)",
  "ai_template_id": "string",
  "acceptable_answers": [
    "string",
    ...
  ],
  "guidelines": [
    {
      "student_answer": "string",
      "mark": number (0 or 1),
      "comment": "string"
    },
    ...
  ] (optional),
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "string" for this question type

stem (string, required):
- HTML content containing the question text
- May include formatting tags (p, span, strong, etc.)
- Typically asks for a text response

ai_template_id (string, required):
- AI template identifier used for automated grading
- String value (no specific length requirement, unlike FRQ which requires 12 digits)
- Used by AI system to evaluate student responses

acceptable_answers (array, required):
- Array of acceptable answer strings
- Each element is a string representing a valid answer
- Used for answer validation and matching
- Can be a single-element array if only one acceptable answer

guidelines (array, optional):
- Array of guideline objects used for AI-based grading
- Each guideline contains:
  * student_answer: String representing an example student answer
  * mark: Number (0 or 1) indicating if this answer should receive full marks (1) or no marks (0)
    - Converted from string or integer in input (must be 1, 0, "1", or "0" only)
    - Always stored as number (0 or 1) in output
  * comment: String providing feedback or explanation for this answer
- Used by AI system to understand grading criteria
- If present, all guidelines must have student_answer, mark, and comment fields

explanation (string or null, optional):
- HTML content explaining the answer or providing feedback
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- ai_template_id must be a non-empty string
- acceptable_answers must be a non-empty array
- Each element in acceptable_answers must be a string
- If guidelines present:
  * Must be an array of objects
  * Each guideline must have student_answer (string), mark (0 or 1, number), and comment (string)
  * mark must be converted to number (not string) in output
