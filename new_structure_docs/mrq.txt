MRQ (Multiple Response Question) - JSON Structure Documentation

ROOT LEVEL (Common to all question types):
{
  "question_id": "string",
  "parent_id": "string or null",
  "language_code": "string (en, ar, etc.)",
  "language": "string (English, Arabic, etc.)",
  "country_code": "string (eg, us, etc.)",
  "country": "string (Egypt, United States, etc.)",
  "subject": "string",
  "subject_id": "string (required)",
  "grade": "string",
  "grade_id": "string (required)",
  "number_of_parts": 1,
  "section_id": "string",
  "source": "string",
  "content": {
    "parts": [...]
  }
}

MRQ PART STRUCTURE:
{
  "n": 1,
  "type": "mrq",
  "stem": "string (HTML content)",
  "choices": [
    {
      "label": "string (A, B, C, D, etc. or Arabic equivalent)",
      "value": "string (HTML content)",
      "is_correct": boolean
    },
    ...
  ],
  "correct_answer": [
    {
      "label": "string",
      "value": "string (HTML content)"
    },
    ...
  ],
  "explanation": "string (HTML content) or null"
}

FIELD DESCRIPTIONS:

n (integer, required):
- Part number, must match position in parts array
- For single-part questions, always 1

type (string, required):
- Always "mrq" for this question type

stem (string, required):
- HTML content containing the question text
- May include formatting tags (p, span, strong, etc.)

choices (array, required):
- Array of choice objects, each containing:
  * label: Display label (A, B, C, D, etc. for English; أ, ب, ج, د, etc. for Arabic)
  * value: HTML content of the choice text
  * is_correct: Boolean indicating if this choice is correct
- Labels are automatically assigned based on language_code
- English: A, B, C, D, E, F, G, H, I, J
- Arabic: أ, ب, ج, د, ه, و, ز, ح, ط, ي
- Choices are sorted by fixed_order from original data

correct_answer (array, required):
- Array of correct answer objects, each containing:
  * label: The label of a correct choice
  * value: The HTML content of a correct choice
- Must contain at least 2 correct answers
- Each object in array must match a choice with is_correct = true

explanation (string or null, optional):
- HTML content explaining the correct answers
- Extracted from root answer field for single-part questions
- For multipart questions, extracted from corresponding child <div>

VALIDATION RULES:
- At least two choices must have is_correct = true
- correct_answer array must contain all choices with is_correct = true
- All choices must have label, value, and is_correct fields
