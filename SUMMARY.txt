JSON QUESTION CONVERSION TOOL - EXECUTIVE SUMMARY

PURPOSE:
Automated tool to convert educational question JSON files from legacy structure to new standardized structure, with comprehensive validation and error reporting.

CAPABILITIES:
- Converts 12 question types: MCQ, MRQ, GMRQ, FRQ, Ordering, Gap-Text, String, Opinion, Matching, Counting, Puzzle, Input-Box
- Uses JSONata transformation rules for type-specific conversions
- Three-stage pipeline: Pre-validation → Conversion → Post-validation
- Batch processing with progress tracking and error recovery
- Generates detailed error reports with separate warnings tracking (Excel + text logs)

KEY FEATURES:
- Pre-conversion validation ensures input quality (OLD structure)
- Post-conversion validation ensures output correctness (NEW structure)
- Warning system for non-blocking issues (e.g., missing statement in multipart)
- Failed files automatically segregated by failure type
- Supports filtering by question type
- Dry-run mode for validation-only testing
- CLI interface with verbose mode
- BeautifulSoup-based HTML validation for answer explanation fields
- Part-specific explanation extraction for multipart questions
- Supports subject_id and grade_id metadata fields
- Enhanced country code extraction with priority logic (Egypt priority, zz filtering)
- Comprehensive number format handling for input_box (Arabic/Hindi digits, thousand separators)

OUTPUT CATEGORIES:
✓ CONVERTED/ - Successfully converted files
✗ PRE_CONVERSION_VALIDATION_FAILED/ - Invalid input structure (blocking errors only)
✗ CONVERSION_FAILED/ - Transformation errors
✗ POST_CONVERSION_VALIDATION_FAILED/ - Invalid output structure
📊 LOGS_REPORTS/ - Detailed tracking (.xlsx with Errors + Warnings sheets, .log)
⚠️ WARNINGS - Non-blocking issues logged separately (multipart without statement, etc.)

VALIDATION SYSTEM:
- ERRORS: Block conversion, file segregated to failure folder
- WARNINGS: Logged but allow conversion to proceed
  * Tracked in separate Excel "Warnings" sheet
  * Examples: multipart without statement, single-part answer HTML issues
  * Visible in console summary as "Total warnings: N"

SUPPORTED QUESTION TYPES:
mcq, mrq, gmrq, frq, frq_ai, oq, gapText, string, opinion, matching, counting, puzzle, input_box

TYPICAL USAGE:
python3 -B main.py
(Processes all INPUT/ files with detailed progress)
